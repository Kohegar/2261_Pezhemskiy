x = [int(t) for t in input().split()]

i = 0

#### Ответ

```java
public class Main {
    public static void main(String[] args) {
        int[][] a = {
            {5, 8, 2},
            {7, 3, 0},
            {9, 0, 4}
        };

        outer:
        for (int i = 0; i < a.length; i++) {
            for (int j = 0; j < a[i].length; j++) {

    }
}
```

`outer:` — метка внешнего цикла. Когда находится первый ноль, `break outer;` выходит сразу из обоих циклов. Обычный `break` завершил бы только внутренний цикл.

### Задание 5 **(2)**

*Напишите программу на С++, которая прочитает натуральное число* **n**, *создаст вектор
из* **n** *элементов, прочитает значения элементов, добавит последний элемент вектора к каждому элементу
(в том числе и к последнему), найдет и выведет количество положительных и отрицательных элементов вектора
после изменения. Из циклов в программе можно использовать только циклы по коллекции.*

#### Ответ

```cpp
#include <iostream>
#include <vector>

int main() {
    int n;
    std::cin >> n;
    if (n <= 0) return 0;

    std::vector<long long> a(n);
    for (long long &x : a) {
        std::cin >> x;
    }

    long long last = a.back();
    for (long long &x : a) {
        x += last;
    }

    int positive = 0, negative = 0;
    for (const long long &x : a) {
        if (x > 0) ++positive;
        if (x < 0) ++negative;
    }
    std::cout << positive << " " << negative << '\n';
}
```

Все циклы имеют вид `for (элемент : вектор)` — это циклы по коллекции. Переменная `last` хранит исходное значение последнего элемента, поэтому и к нему прибавляется его старое значение.

Пример ввода:
```
4
-5 1 0 2
```
После прибавления `2` вектор станет `[-3, 3, 2, 4]`.

Результат:
```
3 1
```
Три положительных и один отрицательный элемент. Нули не учитываются.

Файл: `Task05/main.cpp`.

### Задание 6 **(3)**

*Представим, что в некотором будущем стандарте* **С++** *появится конструкция*
```
forc(i, from, to)
```
*которая будет раскрываться в следующий код.*
```
{
   int __i = from, __n=to;
   for(const int &i= __i; i < __n; __i++) {
      ...
   }
}
```
*Чем эта конструкция отличается от стандартного цикла* **for**? *Укажите два основных различия.
Напишите программы для демонстрации этих различий.*

*Написанные программы сохраните в папку с номером задания.*

#### Ответ

**Первое отличие — переменную `i` нельзя изменять внутри `forc`.** Она объявлена как `const int &i`, то есть константная ссылка. В обычном `for` значение `i` можно менять. При этом `forc` всё равно меняет скрытый счётчик `__i` после каждой итерации.

Программа для первого отличия:

```cpp
#include <iostream>

int main() {
    std::cout << "for: ";
    for (int i = 0; i < 4; ++i) {
        if (i == 1) ++i;
        std::cout << i << " ";
    }

    std::cout << "\nforc: ";
    {
        int __i = 0, __n = 4;
        for (const int &i = __i; i < __n; __i++) {
            // ++i; // ошибка компиляции: i — константная ссылка
            std::cout << i << " ";
        }
    }
    std::cout << "\n";
}
```

Результат:
```
for: 0 2 3
forc: 0 1 2 3
```

Если убрать `//` перед `++i` внутри модели `forc`, программа не скомпилируется.

**Второе отличие — верхняя граница `to` вычисляется один раз.** В обычном `for (int i = 0; i < limit; ++i)` условие использует текущее значение `limit` на каждой проверке. В `forc` заранее сохраняется `__n = limit`.

Программа для второго отличия:

```cpp
#include <iostream>

int main() {
    int limit = 3;
    std::cout << "for: ";
    for (int i = 0; i < limit; ++i) {
        std::cout << i << " ";
        --limit;
    }

    limit = 3;
    std::cout << "\nforc: ";
    {
        int __i = 0, __n = limit;
        for (const int &i = __i; i < __n; __i++) {
            std::cout << i << " ";
            --limit;
        }
    }
    std::cout << "\n";
}
```

Результат:
```
for: 0 1
forc: 0 1 2
```

В первом цикле `limit` уменьшается и цикл останавливается раньше. Во втором сохранённая граница `__n` остаётся равной 3.

Так как `forc` — вымышленная конструкция, в C++-файлах используется её точная модель из условия задания.

Файлы: `Task06/difference_1.cpp`, `Task06/difference_2.cpp`.

### Задание 7 **(2)**

*Напишите программу на языке* **Python** *для проверки того, что все числа во введенной
последовательности неотрицательные. Если в цикле будет найдено отрицательное число, цикл должен
прерваться и вывести найденное число. Если отрицательных чисел нет, то вывести некоторое сообщение об этом.*

*Программа должна использовать конструкцию* **for break else**.

*Запишите аналогичную программу на С++. Какие изменения в алгоритме решения в ней появились?. Почему?*

*Написанные программы сохраните в папку с номером задания.*

#### Ответ

**Python:**

```python
numbers = [int(x) for x in input().split()]

for number in numbers:
    if number < 0:
        print(number)
        break
else:
    print("Отрицательных чисел нет")
```

`else` у цикла `for` выполняется только тогда, когда цикл закончился без `break`.

**C++:**

```cpp
#include <iostream>
#include <sstream>
#include <string>
#include <vector>

int main() {
    std::string line;
    std::getline(std::cin, line);
    std::istringstream stream(line);
    std::vector<int> numbers;

    int number;
    while (stream >> number) {
        numbers.push_back(number);
    }

    bool found = false;
    for (int x : numbers) {
        if (x < 0) {
            std::cout << x << '\n';
            found = true;
            break;
        }
    }
    if (!found) {
        std::cout << "Отрицательных чисел нет\n";
    }
}
```

В C++ нет конструкции `for ... else`, поэтому добавлена переменная `found`. Когда найдено отрицательное число, она становится `true`. После цикла проверяется `found`: если осталось `false`, отрицательных чисел не было.

Пример ввода: `3 6 -7 5`. Обе программы выводят `-7`.

###  Задание 9 **(3)**
*Напишите программу на языке Python для решения следующей задачи.*

*Задана пронумерованная последовательность логических значений* **t(0),t(1),..,t(n)**, **t(i) ∈ {False,True}**

*Последовательность обладает следующим свойством: существует некоторое число k такое, что
все значения* **t(0),t(1),...,t(k-1)** *равны* **False**, *а все значения* **t(k), ... , t(n)** *равны* **True**,
*то есть слева от* **k** *находятся значения* **False**, *а справа* - **True**. *Последовательность задается
функцией* **t(i)**, *которая возвращает логическое значение. Например, для тестирования эту функцию можно
задать следующим образом.*
```
def t(i):
   return i>=1000
```

*Требуется написать программу, которая найдет число* **k**. *Программа должна реализовывать алгоритм
бинарного поиска. Диапазон поиска задается переменными* **left** и **right**. *На каждом шаге вычисляется
центр диапазона, значение в нем проверяется, после чего диапазон сокращается в два раза.*

*Алгоритм должен быть записан через цикл* **while** *и реализовывать инвариант цикла*

t(left)=False ∧ t(right)=True

```
left = -1
right = 10**18
while ...:
   mid = ...
   if t(mid):
      ...
   else:
      ...
print(...)
```

#### Ответ

```python
def t(i):
    return i >= 1000


left = -1
right = 10 ** 18
while right - left > 1:
    mid = (left + right) // 2
    if t(mid):
        right = mid
    else:
        left = mid
print(right)
```

`left` всегда указывает на значение `False`, а `right` — на `True`.

- Находим середину `mid`.
- Если `t(mid)` равно `True`, сдвигаем правую границу в `mid`.
- Иначе сдвигаем левую границу в `mid`.
- Когда между границами не остаётся целых чисел, `right` и есть первое значение `True`.

Итог для примера из условия: `1000`.

Инвариант выполняется, если изначально `t(-1) = False`, `t(10**18) = True` и функция меняет `False` на `True` только один раз. Для приведённой функции это так.

Файл: `Task09/main.py`.

int main() {

### Задание 2 **(15)**
*Напишите программы на языке С++ с использованием разных видов циклов, ветвлений в полной и краткой форме, переведите их в ассемблерный код без оптимизации и опишите, как реализуются эти конструкции в элементарных командах.
правил.*

#### Ответ

В папке `Extra02` находятся пять отдельных программ на C++ и пять соответствующих файлов ассемблера `.s`. Использованы циклы `for`, `while`, `do while` и два вида `if`.

**1. Цикл `for`.**

```cpp
#include <cstdio>

int loop_for(int n) {
    int sum = 0;
    for (int i = 0; i < n; ++i) {
        sum += i;
    }
    return sum;
}

int main() {
    std::printf("%d\n", loop_for(4));
}
```

Основные команды из `for.s`:
```asm
    mov DWORD PTR -8[rbp], 0
    jmp .L2
.L3:
    mov eax, DWORD PTR -8[rbp]
    add DWORD PTR -4[rbp], eax
    add DWORD PTR -8[rbp], 1
.L2:
    mov eax, DWORD PTR -8[rbp]
    cmp eax, DWORD PTR -20[rbp]
    jl .L3
```

`mov` задаёт значение счётчика. `jmp` переходит к проверке. `cmp` сравнивает `i` и `n`, `jl` возвращает к телу цикла, если `i < n`. `add` изменяет сумму и увеличивает счётчик. Результат: `6`.

**2. Цикл `while`.**

```cpp
#include <cstdio>

int loop_while(int n) {
    int sum = 0;
    int i = 0;
    while (i < n) {
        sum += i;
        ++i;
    }
    return sum;
}

int main() {
    std::printf("%d\n", loop_while(4));
}
```

Команды в `while.s` почти такие же, как у `for`: проверка делается до выполнения тела. Ключевой фрагмент:
```asm
    jmp .L2
.L3:
    mov eax, DWORD PTR -8[rbp]
    add DWORD PTR -4[rbp], eax
    add DWORD PTR -8[rbp], 1
.L2:
    mov eax, DWORD PTR -8[rbp]
    cmp eax, DWORD PTR -20[rbp]
    jl .L3
```

Результат: `6`.

**3. Цикл `do while`.**

```cpp
#include <cstdio>

int loop_do_while(int n) {
    int i = 0;
    int count = 0;
    do {
        ++count;
        ++i;
    } while (i < n);
    return count;
}

int main() {
    std::printf("%d\n", loop_do_while(0));
}
```

Основной фрагмент `do_while.s`:
```asm
.L2:
    add DWORD PTR -8[rbp], 1
    add DWORD PTR -4[rbp], 1
    mov eax, DWORD PTR -4[rbp]
    cmp eax, DWORD PTR -20[rbp]
    jl .L2
```

Здесь проверка расположена после тела. Поэтому тело срабатывает хотя бы один раз, даже если `n = 0`. Результат: `1`.

**4. Краткое ветвление `if` без `else`.**

```cpp
#include <cstdio>

int short_if(int x) {
    int result = 0;
    if (x > 0) {
        result = 10;
    }
    return result;
}

int main() {
    std::printf("%d\n", short_if(2));
}
```

Основной фрагмент `if_short.s`:
```asm
    cmp DWORD PTR -20[rbp], 0
    jle .L2
    mov DWORD PTR -4[rbp], 10
.L2:
```

Если `x <= 0`, условный переход `jle` пропускает присваивание. Иначе выполняется `result = 10`. Результат при `x = 2`: `10`.

**5. Полное ветвление `if / else`.**

```cpp
#include <cstdio>

int full_if(int x) {
    int result;
    if (x > 0) {
        result = 10;
    } else {
        result = -10;
    }
    return result;
}

int main() {
    std::printf("%d\n", full_if(-2));
}
```

Основной фрагмент `if_full.s`:
```asm
    cmp DWORD PTR -20[rbp], 0
    jle .L2
    mov DWORD PTR -4[rbp], 10
    jmp .L3
.L2:
    mov DWORD PTR -4[rbp], -10
.L3:
```

Если `x <= 0`, `jle` переходит к `else`. Если `x > 0`, выполняется первая ветка, а `jmp` пропускает `else`. Результат при `x = -2`: `-10`.

**Вывод.** Процессор выполняет циклы и условия через сравнения (`cmp`), условные переходы (`jl`, `jle`), безусловные переходы (`jmp`) и команды изменения значений (`mov`, `add`).

**Как получить ассемблер без оптимизации:**
```bash
g++ -std=c++17 -O0 -masm=intel -S for.cpp -o for.s
g++ -std=c++17 -O0 -masm=intel -S while.cpp -o while.s
g++ -std=c++17 -O0 -masm=intel -S do_while.cpp -o do_while.s
g++ -std=c++17 -O0 -masm=intel -S if_short.cpp -o if_short.s
g++ -std=c++17 -O0 -masm=intel -S if_full.cpp -o if_full.s
```

В приложенном архиве файлы `.s` получены компилятором GCC 14.2.0 для x86-64 с параметрами `-O0 -fno-asynchronous-unwind-tables -fno-stack-protector -masm=intel -S`. Дополнительные ключи убирают часть служебных инструкций, но не включают оптимизацию. В других компиляторах и на других процессорах ассемблерный код может немного отличаться.
